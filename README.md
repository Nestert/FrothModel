# Приложение для обнаружения объектов на видео с YOLO

Веб-приложение на Streamlit для обнаружения объектов на видео с использованием предобученной YOLOv8 модели сегментации.

## Возможности

- Загрузка и обработка видео файлов
- Настройка порога уверенности и IoU
- Визуализация результатов обнаружения
- Отображение прогресса обработки

## Требования

- Python 3.8+
- Установленные зависимости из файла `requirements.txt`
- Предобученная модель YOLO (файл `yolo11n-seg.pt`)

## Установка и запуск

1. Клонируйте репозиторий или скачайте файлы

2. Установите зависимости:
```
pip install -r requirements.txt
```

3. Убедитесь, что файл модели `yolo11n-seg.pt` находится в корневой директории проекта

4. Запустите приложение:
```
streamlit run app.py
```

5. Откройте браузер по адресу http://localhost:8501

## Использование

1. После запуска приложения загрузите видео файл через интерфейс
2. Настройте параметры обнаружения (порог уверенности и IoU)
3. Нажмите кнопку "Обработать видео"
4. Дождитесь завершения обработки
5. Просмотрите результат с обнаруженными объектами
